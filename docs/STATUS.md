1. **没有近期可用的备份。** 工作流已关闭，本机定时任务 2026-08-03 起暂停。
2. **R2 公开桶可匿名下载 7 月的明文备份。**
3. **GitHub 免费版没有分支保护。** CI 失败也能合并，工作流备份的解封条件也无法满足。
4. **生产恢复步骤。** 见 `V1_PRODUCT_STATUS_AND_PLAN_2026-08-03.md` 阶段 2，写于 8 月，执行前须对照当前 main 重新核对。
